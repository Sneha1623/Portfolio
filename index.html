WIRELESS SENSING / AI / IoT

EAGLE Δ — Contactless Indoor Sensing via Wi-Fi CSI

Camera-free, privacy-preserving indoor sensing application using ESP32 Wi-Fi Channel State Information to detect human presence and motion without optical surveillance.

TECHNICAL HIGHLIGHTS:

  • Extracted sub-carrier CSI packets directly from ESP32 transceivers.
  • Programmed firmware in ESP-IDF & C/C++ for precise temporal capture.
  • Applied offline Python signal analytics & noise filtering algorithms.
  • Persisted contactless motion event telemetry locally in SQLite storage.
ESP32 ESP-IDF Python Signal Processing SQLite
Outcome: Developed a cloud-independent indoor sensing and offline signal analytics pipeline for privacy-sensitive environments.
