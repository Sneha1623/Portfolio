# 🚀 Featured Projects

## 🦅 EAGLE — Contactless Indoor Sensing via Wi-Fi CSI

A camera-free and privacy-preserving indoor sensing system using **Wi-Fi Channel State Information (CSI)**.

### Key Features

- Uses ESP32 subcarrier amplitude data for indoor sensing
- Detects human presence and motion in real time
- Processes Wi-Fi CSI signals using Python
- Uses SQLite for local and offline signal logging
- Provides a privacy-preserving alternative to camera-based sensing

### Tech Stack

`ESP32` `ESP-IDF` `C/C++` `Python` `SQLite` `Signal Processing`

🔗 **Repository:**  
https://github.com/Sneha1623/EAGLE-CSI

## ☀️ SouryaNova — AI-Powered Solar Energy Monitoring Platform

An end-to-end **IoT and AI-based solar energy monitoring platform** designed to monitor solar panel performance and identify performance degradation.

### Key Features

- Real-time solar panel monitoring
- Irradiance, temperature and dust monitoring
- ESP32-based sensor integration
- MQTT communication between ESP32 and backend
- Node.js backend for real-time data handling
- Predictive AI models for performance degradation
- Automated maintenance alerts

### Tech Stack

`Python` `TypeScript` `Node.js` `SQL` `MQTT` `ESP32` `Wokwi`

🔗 **Repository:**  
https://github.com/Sneha1623/SouryaNova
